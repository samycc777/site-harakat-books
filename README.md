# كتب مشكولة

Salafi books with full harakat (tashkeel), free to read and download as PDF:
**https://harakat-books.pages.dev**

كتب سلفية مشكولة تشكيلا كاملا، للقراءة والتحميل مجانا.

- Found a mistake in a book? Use «إبلاغ عن خطأ» at the bottom of the book's page, or open an issue here.
- This repository holds the site only (`public/`); `scripts/sync.py` builds the pages.
